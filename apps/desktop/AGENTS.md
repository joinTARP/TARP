# 桌面应用约定

- 使用中文交流和中文 Markdown 文档。
- 本目录是 TARP Bun workspace 的 `@jointarp/desktop` 子包；依赖在仓库根目录安装，锁文件由根目录统一维护。
- 保留 TypeScript 7、Electrobun（Bun 主进程、系统 WebView）和 Oxfmt；Git 钩子由仓库根目录管理。
- 测试优先覆盖可观察行为并复用已有场景；简单映射、纯透传和样式调整不新增独立测试文件。测试范围与维护原则见 `../../docs/测试维护.md`。
- 源码仓库只维护开发环境、内部契约、架构、实现、扩展、恢复、测试和发布文档；玩家指南与模组配置规范统一在官网文档维护，不在 README 或 `docs/` 复制教程、参数表和完整配置示例。影响公开行为或模组格式时同步更新官网正文。跨仓库文档引用使用公开地址，不依赖本地目录布局。
