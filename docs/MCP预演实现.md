# MCP 预演实现

桌面主进程通过本地 Streamable HTTP 暴露模组预演能力，使用官方 `@modelcontextprotocol/sdk`。设置页的“开发者工具”提供服务开关、状态、最近请求时间和复制连接配置。默认关闭，启停立即生效，开关状态会保存。服务只监听 `127.0.0.1`，校验令牌和 Host，并拒绝浏览器 Origin 请求。

主进程在应用配置目录的 `mcp-settings.json` 保存开关、端口和随机令牌，权限为 `0600`；首次开启自动分配端口，之后沿用端口和令牌。启动时另写发现文件 `mcp.json`，停止后移除。未设置 `TARP_HOME` 时配置目录为 `~/.tarp`。复制操作由主进程写入剪贴板，状态 RPC 不返回令牌。启动失败显示错误并允许重试，不阻止应用启动，也不会自动更换端口，以免已有连接配置失效。

源码调试同样通过设置页启停服务，开关、端口与令牌统一使用已保存的配置。测试数据和工具参数在官网模组预演正文维护。

## 宿主与数据边界

- `apps/desktop/src/main/mcp/service.ts` 管理私有配置、运行状态、复制连接配置与串行启停。每次开启创建新的预演服务；关闭等待取消收尾，保留临时局。重新开启只恢复 MCP 监听，不恢复预演任务。
- `mcp/server.ts` 负责工具、传输和本地访问验证。每个 HTTP 请求使用独立 SDK 实例，预演生命周期由主进程服务管理，不绑定 HTTP 连接。
- `mcp/playtest.ts` 负责临时 session 创建、运行上限、暂停、读取和清理，复用当前玩家身份、模型连接及同一个 `ChatService`。调用现有游戏路由显示测试局，游戏页不增加托管按钮。
- `createSession` 的初始文档参数只修改未发布的 staging 模组副本。路径按文档身份解析并防止目录穿越；替换顶层字段后重新加载，校验字段、公式、引用、开局和状态。初始值不受运行期 `mutable` 限制，但运行工具权限不变。禁止覆盖公式配置，失败清理 staging。
- 创建后选择已有开局及有模组 AI 预设的角色，准备旁观者进度并跳过实际开场。位置、场景和成员关系通过前置文档字段表达，由模组规则和主持解释；预演服务不维护额外场景分配。
- 公开背景保存为预写消息；主持背景附加到本局主持提示词。队友只接收公开背景和现有公开资料。不伪造 Pi 会话或已有游戏历史。

临时局使用当前标准存档格式，额外 `playtest.json` 保存版本 `1`、房间 ID、输入 fixture、计算后的初始状态及每步快照。标记不属于房间同步协议；只有带合法标记的 session 才可由 MCP 运行或删除。临时局在显式清理前保留，应用重启后可再次读取，未完成消息按既有恢复机制处理；运行计时器不跨重启恢复。

## 运行边界

`ChatService.playtestTurn` 在现有房间互斥内完成一次队友决策及其行动的主持裁定。`RunOptions.singleTurn` 保留真实工具、掷骰、输入接收、提交与界面通知，抑制此次运行的自动点名与队友接续，由预演服务驱动下一步。

队友按席位顺序轮换，跨多次单步调用继续轮换。运行步数按队友决策计数，聊天或沉默也占一步；队友提交实际行动后才调用主持。全体队友连续未提交行动即等待干预。达到次数上限、房间结束、超时、失败或停止时不启动下一步。暂停取消当前生成并等待收尾，不撤销已保存的变化。中断后留有未接收批次或待处理行动时拒绝继续，调用方检查记录或从同一 fixture 重建。

运行异步返回，通过 `inspect` 读取进度。活动状态来自房间 `chatActivity`；对话与骰子来自实际聊天记录；文档和步骤快照使用真实计算接口。默认返回 fixture 指定文档及队友文档，可按路径查询其他资料。聊天按现有序号分页，不根据最近一页的内容判断运行是否结束。报告可能包含主持信息，属于开发调试结果。

退出应用时先停止 MCP 接收、取消预演并等待收尾，再关闭聊天。清理临时局同样先等待运行退出再删除。

## 验证

集成测试位于 `apps/desktop/src/main/mcp/playtest.test.ts`，复用独立平台测试模组。覆盖真实存档与公式、有限次数调度、源文件不变、非法 fixture 清理、普通冒险保护、并发启动和取消，以及官方 MCP 客户端到 HTTP 服务的完整调用。服务管理测试覆盖默认关闭、凭据与端口持久化、状态不含令牌、主进程复制、端口冲突重试，以及关闭取消和重新开启不续跑。

测试使用受控模型输出，不代表实际模型一定遵守规则或图形界面已验收。修改预演链路后执行平台完整回归、类型检查和桌面构建；真实模型试玩需要客户端已有模型连接。
