# 统一主持输入接收确认

真人与 AI 队友的行动归一为同一输入批次，由应用持久保存原始发言和身份快照，Pi 在包含实际输入的同一条原生记录中保存批次接收标记。应用只在该条目成功写入后确认接收；原生成功而应用确认失败时，沿有效分支对账恢复，不以模型返回或队列移除推断送达。

批次快照保存在内部输入批次表中，与主持消息关联，来源消息从待提交列表移出表示领取，不表示接收。未接收失败批次阻止新行动，房主重试原批次或放弃后继续；允许仅聊天，停止和重启不自动提交。已经接收的行动、工具结果与状态保留，不能把生成失败当作重新投递的理由。代价是新增接收对账与显式处置；相较队友最近行动反复重送，它同时补足真人输入的失败窗口，并避免重复裁定。

去重只减少未来追加的内容，已有历史保持原样直到正常压缩，不逐轮替换历史快照，以保留缓存可复用的输入前缀。详细契约见[游戏聊天与 AI 实现](../游戏聊天与AI实现.md)。
