# 文档标识与会话 JSON 副本

模组作者可使用 JSON、TOML 或 Markdown，创建冒险时在 staging 副本中将游戏文档、元配置、字段定义和布局统一为 JSON，阅读页与附件保留原文件。运行时文档标识保留目录、名称和类型，忽略最后的格式扩展名；各入口解析唯一实际路径后再交给存储、版本和缓存，避免同一文档因输入别名形成多份状态。

转换保留业务原值、公式、正文和引用字符串，计算结果仍在运行时求值；不逐个改写引用。代价是作者文件与会话文件的格式不同，以及搜索必须解码正文才能保留逐行检索。同名多格式直接报冲突，禁止以精确路径优先级选取内容；角色音色也按文档标识匹配，附件与阅读页继续使用实际路径。
