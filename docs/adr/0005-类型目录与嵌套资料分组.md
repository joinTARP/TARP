# 类型目录与嵌套资料分组

游戏文档的一级目录使用文档类型 ID，任意深度的子目录只承担资料分组，所有后代文档继承一级目录的类型。文件名去掉重复的类型后缀，文档身份由类型目录、分组路径与名称共同确定，仍忽略最后的格式扩展名；不同分组允许同名文档，同一路径的多格式文件仍冲突。字段定义、元配置、阅读页和附件不按游戏文档规则推导类型。

这一约束支持大型模组按探险、战斗等主题继续组织同一类型的资料，并减少文件名中的重复类型信息；代价是同一类型目录不能混放不同类型的游戏文档。目录索引继续显式区分文件夹路径与其下的文件名，由模型拼接读取路径。加载、校验、引用、编译和运行时读写统一使用类型目录，取代通过文件名类型后缀识别文档类型的实现。
